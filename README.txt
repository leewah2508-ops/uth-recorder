UTH Hand Recorder
=================

This is a static web app. Serve this folder through any basic web server.

Quick local test on macOS/Windows/Linux:
  python3 -m http.server 8080
Then open:
  http://localhost:8080

For iPhone use, host the folder on any HTTPS static host and use Safari > Share > Add to Home Screen.

Defaults:
- Jackpot $10
- Trips $0
- Ante $25
- Starting bankroll $3,000

Session data is stored locally in the browser using localStorage.
